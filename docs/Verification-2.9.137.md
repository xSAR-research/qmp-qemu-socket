### Correction and bounds

- Ordinary effects check immediately after their existing settle, using two seconds
  from the **whole action's last ACK**. MOVE's 250 ms and RECYCLE's 1,000 ms settle
  consume that same window. MATCH/KING still impose no fixed two-second sleep.
- A 50 ms read-only retry clamps to the remaining time. No new capture starts
  at/after expiry. A capture already in flight may complete later; STOP/context
  is checked before accepting it. Unknown effects grant no retransmission.
- The finite effect ceiling is `ceil(2000 / 50) + 1 = 41`; the elapsed window can
  stop earlier. With zero capture latency, only starts from 0 through 1950 ms are
  allowed. Shared sequencing, the local guard and checked total capture allowance
  use the same derived ceiling. Source checks retain six reads; final proof keeps
  its separate 20-read/two-second policy.
- Recognition signatures/tolerances, whole-action source/permit ownership,
  terminal-first input-free handoff, REDEAL, next-board reset, CV/HALO timing and
  input ordering/holds are unchanged. Failure metadata distinguishes the ordinary
  and final confirmation windows.
