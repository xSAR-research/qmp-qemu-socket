# Verification — 3.1.0 / xSAR 0.11.0

Adds an offline Free Cell complete-route calculation from a strict saved 52-card deal. The dedicated worker freezes the loaded input, searches without configured memory/time/state/expansion limits, records root and interleaved Horne automatic transfers, and independently replays every transfer before publishing a usable complete route. Foundations are irreversible. Guidance orders the search; no shortest or optimal route is promised.

The UI provides a direct Pyramid/Free Cell selector, JSON file selection, CALCULATE, PAUSE/CONTINUE and CANCEL, actual counters and measured paused duration. Request/context/source-generation fencing rejects stale results. Calculation performs no capture, QMP or guest input; later move execution and partial optimisation remain separate work.

## Code Analysis

The library owns checked physical state/rules, exact permutation equality, immutable arena ancestry and independent replay. Generic unlimited storage bypasses configured budgets while retaining fallible growth and arithmetic checks; existing bounded callers retain their limits. Automatic foundation transfers are deterministic monotone edges and remain explicit in the returned route. Replay independently validates identities and physical legality after each transfer.

The application owns one frozen offline job, latest-only advisory progress, authoritative completion statistics, source/context identity and cooperative pause/cancel. No live acquisition is authenticated and no execution permit is produced. UI source changes and duplicate/stale completions are fenced; cancellation wakes paused work. Input JSON retains its existing 65,536-byte bound, which is distinct from search resource policy. No shortest-route guarantee, general runtime guarantee, new Miri evidence or fresh native guest acceptance follows from these host tests. The adopted foundations are irreversible. Block 3 optimisation and Blocks 4–5 execution remain separate.

Four repository histories/indices and all unowned tracked patches/status are preserved, including capture-server staged and unstaged edits. Prior compiler/document/evidence pins are checked before closeout. Seven measured lifecycle additions are pinned without claiming old sidecar contents or database logical equivalence. Baseline untracked content outside existing pins was not retrospectively attested. The restricted editable task documents are hash-only. The new verifier requires an independent receipt digest; future source, normal-target rebuilds or lifecycle changes can cause a specific regression and must not be silently relabelled.
